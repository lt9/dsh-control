# 家里生图（ComfyUI / Qwen-Image-2.1-Turbo）

一条命令出图，**不要自己拼 HTTP**：

```bash
SKILL=/data/skills/comfy-image          # 家庭版实例里技能就在这个目录
set -a; . "$SKILL/config.env"; set +a   # 读入服务地址与 token
python3 "$SKILL/comfy_generate.py" "一枚蓝色圆形徽章，米白底，极简扁平风格" \
    --w 1024 --h 1024 --out 徽章.png
```

产物请存到**当前工作区**（上面 `--out 徽章.png` 就是存到工作区根），这样 `present` 能直接给他看。

先确认服务活着（不确认就直接生图，失败了分不清是哪一段的问题）：

```bash
python3 "$SKILL/comfy_generate.py" --status   # 显存、在线状态、队列长度；连不上会说明原因
```

## 硬规矩（都是实测出来的，别自由发挥）

| 事 | 规矩 | 为什么 |
| --- | --- | --- |
| 尺寸 | 宽高取 **16 的倍数**；方图 1024×1024、卡片 1024×1360、横版插图 1536×864 | 不是 32 的倍数；超过 1536×864 这个量级会爆显存 |
| 步数 | 保持默认 **8 步 / CFG 1** | Turbo 是 8 步蒸馏版，调大只会慢 5 倍且更糊 |
| 种子 | 不传 `--seed`（默认随机） | 同 prompt + 同 seed 命中缓存，2 秒返回**字节相同**的图，看着像成功其实没重新画 |
| 一次一张 | 别并发投、失败别立刻重交 | 单卡串行队列，重交等于排两次队 |
| 超时 | 整单等到 120 秒再判失败 | 排队时前面可能有别人的任务 |
| 文字 | 单行大标题可靠；**三行以上正文会画成假字** | 需要准确的文字用 office 技能做真文档，别指望生图 |

## 图生图（同一套卡片保持风格一致，只换内容）

```bash
python3 "$SKILL/comfy_generate.py" "参考这张图的配色和排版，把标题换成「第二季度」，其他保持一致" \
    --ref 卡片1.png --denoise 0.55 --out 卡片2.png
```

`--denoise` 0.4–0.6 保风格换内容，>0.7 变化太大。参考图先缩到 1024 见方。

## 出完图必须做的事

1. **看一眼再交付**：`read_image` 读一遍产物，文字类版面尤其要看有没有丢字、假字。
2. **产物存到工作区**（默认当前目录即可），交付用 `present`，别只说文件名。
3. **图要进 PPT/Word**：先生成 PNG，再用办公技能把它插进文档，例如
   "用 office-pptx 把 徽章.png 放进第 2 页右侧"。生图和做文档是两步，不要指望生图直接出 PPT。

## 失败了照这张表做，别猜

| 现象 | 原因 | 该做的 |
| --- | --- | --- |
| `401` | `config.env` 丢了或 token 不对 | 告诉管理员"生图 token 需要重新铺一次"，控制台点重启会重铺 |
| `502` | 门卫活着但生图后端没起——**最常见是语音转写正占着这张卡**（两栈互斥） | 找管理员切回生图栈；**不要反复重试狂戳** |
| 连不上 / 超时 | 那台 Windows 机器没开机，或链路故障 | 客户端会自动试备用入口；仍不通就是机器没开机，找管理员 |
| 提示词报错 400 | 工作流 JSON 被改坏 | 别改 `comfy_generate.py` 里的固定节点，找管理员 |

**任何情况下都不要在这台机器上试图重启生图服务或切换栈**（生图在另一台 Windows 机器上，这里的操作既够不着又会伤到别的服务）。
